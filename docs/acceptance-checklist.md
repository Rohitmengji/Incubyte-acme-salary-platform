### Not delivered, or known limitations

- ❌ **Docker and Docker Compose**: dropped by decision.
- ⚠️ **Rate limits are in memory**, per process or function instance, and the API doesn't see the client's real IP behind Vercel's proxy. The per-account and per-session limits still apply.
- ⚠️ **Live latency from India** is about 0.3–0.6 s per request, because the hosting is in US East.
- ⚠️ **The live demo uses published demo passwords** (with an explicit opt-in). That's acceptable only because the data is synthetic.
- ⚠️ **Not measured:** Core Web Vitals on real devices and networks, Lighthouse, and a distributed load test.
- ⚠️ **No automated tests** for three behaviours: the stale-correction reload, the salary-change dialog's fresh defaults, and the histogram snapshot under concurrent edits. They're checked by code review ([review](./production-readiness-review.md#not-fixed-known-limits-and-trade-offs)).
- **Out of scope by design:** payroll, tax, SSO and MFA, live FX rates, approvals, and a user-management UI ([requirements](./requirements.md#out-of-scope-deliberately)).
